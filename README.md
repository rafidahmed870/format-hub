# Format Hub

A fast, offline desktop app to convert images, audio, and video between any format, built with Tauri and Rust.

## Features

- Images: PNG, JPG, WEBP, GIF, BMP
- Audio: MP3, WAV, FLAC, AAC, OGG
- Video: MP4, MKV, MOV, WEBM, AVI

## Stack

React · TypeScript · Tailwind · Rust · Tauri

## Run

```bash
npm install
npm run tauri dev
```

## Build

```bash
npm run tauri build
```
